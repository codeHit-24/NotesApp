# 🖤 Kuromi Notes App (AI Powered)

A cute and modern Android Notes application with AI-powered note summarization and a Kuromi-inspired UI theme.

---

## ✨ Features

- 📝 Create, edit, and delete notes  
- 🔍 Search notes instantly  
- 🎀 Kuromi-themed UI design  
- 🤖 AI-powered note summarization (Pollinations AI)  
- 📱 Multi-activity Android architecture  
- ⚡ Fast and lightweight performance  

---

## 🧠 AI Feature

The app includes an AI summarization feature that generates short summaries of notes using a cloud-based LLM inference API.

---

## 🛠 Tech Stack

- **Language:** Java  
- **UI:** XML, ConstraintLayout  
- **Networking:** OkHttp  
- **AI API:** Pollinations AI  
- **IDE:** Android Studio  
- **Version Control:** Git & GitHub
